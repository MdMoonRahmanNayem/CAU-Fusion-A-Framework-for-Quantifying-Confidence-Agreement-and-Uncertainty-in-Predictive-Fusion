# CAU-Fusion

## A Framework for Quantifying Confidence, Agreement, and Uncertainty in Predictive Fusion

CAU-Fusion is a reliability-aware prediction fusion framework developed for diabetic retinopathy prediction using clinical records and retinal fundus images.

The framework uses two separate models for prediction. **CatBoost** is used to process structured clinical data, while **DenseNet121** is used to analyze retinal fundus images. Instead of directly averaging their prediction probabilities, CAU-Fusion considers prediction confidence, agreement, disagreement, and uncertainty before generating the final prediction.

## Project Overview

Clinical records and retinal fundus images provide different types of information for prediction. In this project, they are processed separately using specialized models, and their prediction probabilities are combined at the prediction stage.

The selected models are:

- **CatBoost** — Clinical data
- **DenseNet121** — Retinal fundus images
- **CAU-Fusion** — Prediction probability fusion

The clinical model generates a clinical prediction probability `Pc`, and the image model generates an image prediction probability `Pi`. These probabilities are then passed to the CAU-Fusion process to produce the final probability `Pfinal`.

The underlying CAU-Fusion strategy is not limited to diabetic retinopathy and can potentially be adapted to other disease prediction and healthcare prediction tasks by using appropriate data and prediction models.

## CAU-Fusion

The CAU-Fusion framework receives the prediction probabilities generated by CatBoost and DenseNet121.

The main processing stages are:

* Probability Calibration
* Feature Engineering
* Hyperparameter Tuning
* Threshold Optimization
* Confidence Estimation
* Agreement Analysis
* Uncertainty Estimation
* Final Probability Generation

The framework first calculates a simple fusion score from the two calibrated probabilities. Confidence is used as a positive factor, while disagreement and uncertainty are used as penalty terms.

### Core Components

#### Simple Fusion

The simple fusion score is the unweighted average of the calibrated clinical and image probabilities:

```text
S = 0.5 × Pc' + 0.5 × Pi'
```

#### Agreement

Agreement represents how closely the two prediction probabilities match:

```text
D = |Pc' − Pi'|

Agreement = 1 − D
```

A lower disagreement value indicates stronger agreement between the predictions.

#### Confidence

The confidence component combines the certainty of the individual predictions with their agreement. This allows reliable and consistent predictions to have greater influence during fusion.

#### Disagreement

Disagreement measures the difference between the calibrated clinical and image probabilities:

```text
D = |Pc' − Pi'|
```

A higher disagreement value indicates stronger conflict between the predictions.

#### Entropy-Based Uncertainty

Prediction uncertainty is calculated using binary entropy:

```text
H(p) = −[p log₂(p) + (1 − p) log₂(1 − p)]
```

The uncertainty of the two predictions is then averaged.

#### Final Fusion

The final probability is calculated as:

```text
Pfinal = [S × (1 + γ × cf)] /
         [1 + α × D + β × U + ε]
```

Where:

* `S` = Simple Fusion score
* `cf` = Confidence factor
* `D` = Disagreement
* `U` = Uncertainty
* `α` = Disagreement penalty parameter
* `β` = Uncertainty penalty parameter
* `γ` = Confidence gain parameter
* `ε` = Small constant for numerical stability

The parameters `α`, `β`, and `γ`, together with the decision threshold, are optimized through grid search using Balanced Accuracy.

## Dataset

The project uses clinical records and corresponding retinal fundus images linked using a unique `Image_ID`.

### Clinical Data

The clinical dataset includes:

* Age
* Gender
* Urea
* Creatinine
* HbA1c
* BMI
* Cholesterol
* Triglycerides (TG)
* HDL
* LDL
* VLDL

The target variable `CLASS` contains diabetic and non-diabetic classes.

### Retinal Fundus Images

The retinal dataset contains fundus images corresponding to the clinical records.

A unique `Image_ID` establishes a one-to-one relationship between each clinical record and its corresponding retinal image.

## Data Preprocessing

### Clinical Data

The clinical preprocessing pipeline includes:

* Duplicate removal
* Inconsistent-value correction
* Missing-value handling
* Categorical feature encoding
* Target encoding
* Input feature and target preparation

A stratified train-test split was used for the clinical data. **SMOTETomek** was applied to the training data to address class imbalance.

The retinal images were:

* Resized to `224 × 224`
* Normalized
* Augmented using rotation
* Augmented using zooming
* Augmented using horizontal flipping

Sampling and augmentation were applied only to the training data, while validation and testing data remained unchanged for evaluation.

## Why CAU-Fusion?

Simple probability averaging does not explicitly consider whether the prediction outputs are reliable or whether they strongly disagree.

CAU-Fusion addresses this by considering:

```text
Clinical Probability (Pc)
          +
Image Probability (Pi)
          ↓
Probability Calibration
          ↓
Simple Fusion
          ↓
Confidence + Agreement
          ↓
Disagreement + Uncertainty
          ↓
Final Fusion Probability
          ↓
Final Prediction
```

The approach increases the influence of reliable predictions while reducing the influence of conflicting and uncertain predictions.

## End-to-End Workflow

For a prediction, the framework follows these steps:

1. Obtain the clinical record and corresponding retinal fundus image.
2. Generate the clinical probability using CatBoost.
3. Generate the image probability using DenseNet121.
4. Calibrate the prediction probabilities.
5. Calculate Simple Fusion, Confidence, Agreement, Disagreement, and Uncertainty.
6. Apply the optimized fusion parameters.
7. Apply the optimized decision threshold.
8. Generate the final probability and prediction.

## Key Contribution

The main contribution of CAU-Fusion is its reliability-aware prediction fusion strategy.

Instead of treating the prediction outputs equally, the framework explicitly considers:

* Prediction confidence
* Agreement between predictions
* Disagreement between predictions
* Entropy-based uncertainty

This allows the final prediction to account for both the prediction values and their reliability.

The underlying fusion strategy can potentially be adapted to other disease prediction and healthcare prediction tasks where prediction outputs need to be combined while considering confidence, agreement, and uncertainty.

## Conclusion

CAU-Fusion presents a reliability-aware approach for diabetic retinopathy prediction by combining prediction outputs from clinical data and retinal fundus image models. CatBoost is used for clinical data classification, while DenseNet121 is used for retinal fundus image classification. Instead of simply averaging their prediction probabilities, the framework considers confidence, agreement, disagreement, and uncertainty during the fusion process.

The experimental results demonstrated strong performance from both selected models, with CatBoost achieving 99.00% accuracy and 100.00% recall, while DenseNet121 achieved 98.77% accuracy, 99.81% recall, and 99.96% ROC-AUC. Overall, the project demonstrates how reliability-aware prediction fusion can improve the consideration of model consistency and uncertainty when generating a final prediction. The underlying strategy also provides a basis for potential adaptation to other disease prediction and healthcare prediction tasks.
